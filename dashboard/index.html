    지표 정의 및 데이터 한계

    지표 정의

    보도 건수
    선택 기간에 수집된 관련 온라인 기사 수(URL 기준 중복 제거).
    통합 이슈
    제목이 비슷한 기사(문자 2-gram 자카드 유사도 0.45 이상, 3일 이내)를 하나의 이슈로 묶은 수.
    보도 매체
    기사를 낸 서로 다른 언론사 수.
    확인 조회수 · 공개율
    원문에 조회수가 공개된 검증 매체 기사의 조회수 합계와, 전체 기사 중 조회수를 확인한 비율.
    이슈당 평균 보도
    보도 건수 ÷ 통합 이슈 수. 하나의 보도자료가 평균 몇 건으로 퍼졌는지 나타냄.
    대형 확산 이슈
    5개 이상 매체가 보도한 이슈 수.
    매체 다양성 · 이슈 집중도
    매체 다양성 = 1 − HHI(매체별 점유율 제곱합). 이슈 집중도 = 상위 10% 이슈가 차지하는 보도 비중.
    증감
    선택 기간과 같은 길이의 직전 기간 대비 변화율.

    데이터 한계

    • 포털 뉴스 검색 API 결과를 기반으로 하므로 검색어에 걸리지 않는 기사, 지면·방송 보도는 누락될 수 있음.
    • 조회수는 원문에 조회수를 공개하는 일부 매체에서만 확인되며, 전체 도달 규모를 대표하지 않음.
    • 이슈 통합은 제목 유사도에 따른 자동 분류이므로 일부 오분류가 있을 수 있음.
    • 주제는 키워드 기반 자동 분류이며, 하나의 기사는 하나의 주제로만 집계됨.
    • 보도량과 다른 지표의 상관은 인과관계를 의미하지 않음.
