AI로 만드는 지역 홍보 성과 분석 시스템

코딩 경험이 없어도, AI와 함께 지역 뉴스를 수집·분석하는 대시보드를 직접 만들고 배포합니다.

과정 살펴보기 ↓실습 사례 보기
01

과정 소개

지자체는 보도자료를 배포해 시정을 알리고 있습니다. 하지만 그 홍보가 실제로 얼마나 보도되고 퍼졌는지는 확인하기 어렵습니다. 이 과정에서는 AI 코딩 도구와 함께 홍보 성과를 데이터로 보여 주는 웹 대시보드를 직접 만듭니다. 실제 운영 중인 「아산시 홍보 사업 성과 분석 시스템」을 따라 만든 뒤, 각자 원하는 지역으로 바꿔 배포합니다.

코딩 경험이 없어도 괜찮습니다. 단계별 프롬프트를 AI에 입력하고, 결과를 확인하고, 고쳐 달라고 요청하는 방식으로 진행합니다.
02

이런 분께 권합니다

지자체·공공기관 홍보 담당자

의정 활동 지원·모니터링 담당자

지역 언론, 시민단체, 연구자

AI로 실무 도구를 직접 만들어 보고 싶은 분

03

무엇을 만드나요

뉴스 자동 수집

매일 아침 지역 관련 온라인 기사 수집 (네이버 뉴스 검색 API, 빅카인즈 API)

이슈 통합

제목이 비슷한 기사를 하나의 이슈로 묶고 보도 건수 집계

대시보드

일간·주간·월간 현황, 기간 설정, 매체·분야별 분석

통계 보고서

상관분석·유의성 검정 결과를 Gemini가 개조식으로 해석

운영

관리자 로그인, 수동 갱신 버튼, 매일 자동 갱신, 무료 웹 배포

내 지역으로 확장

검색어와 지역명만 바꾸면 어느 지자체에도 그대로 적용

04

진행 순서

  1. 1

    준비

    계정 만들기와 API 키 발급 (GitHub, 네이버 API HUB, Gemini, Render)

  2. 2

    골격과 수집

    폴더·DB 만들기, 뉴스 수집과 정제

  3. 3

    분석

    유사 제목 통합, 통계 분석과 AI 해석

  4. 4

    화면

    대시보드와 보고서 페이지, 관리자 페이지

  5. 5

    배포와 자동화

    GitHub Actions 매일 수집, Render 웹 배포

  6. 6

    내 지역으로 바꾸기

    검색어·지역명 교체, 보안 점검

05

준비물

  • 노트북(Windows 또는 Mac)과 크롬 브라우저
  • GitHub, Google, 네이버 계정
  • AI 코딩 도구 — Claude 또는 Gemini 유료 버전 권장
    무료 버전은 사용량 제한으로 실습이 끊길 수 있습니다.
  • Python 3.12, Node.js 18 이상 · 첫 시간에 함께 설치
06

수료 후 얻는 것

  • 내 지역 홍보 성과 대시보드 — 공유 가능한 웹 주소
  • 내 GitHub 저장소와 매일 자동으로 쌓이는 뉴스 데이터
  • 단계별 프롬프트 모음 — 다른 주제에도 다시 활용
